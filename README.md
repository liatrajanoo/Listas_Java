## Como rodar no Eclipse
1. `File > Import > General > Existing Projects into Workspace`
2. Selecione a pasta `listas-java` e clique em Finish.
3. Abra a pasta do exercício, clique com o botão direito no arquivo com `main` (`Main.java` ou `ExercicioNN.java`) e escolha `Run As > Java Application`.
